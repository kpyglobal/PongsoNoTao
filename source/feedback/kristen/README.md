# Kristen 的回饋資料夾

這個資料夾給 Kristen（本專案的主要負責人）放回饋、筆記、參考資料和素材。開發時會讀這裡的內容來學習、照著修改。

## 怎麼放
- **一則回饋一個檔案**，檔名用日期開頭：`2026-11-20-服裝細節.md`。可以直接複製 `TEMPLATE.md` 來寫。
- **照片、掃描、錄音、文件**等素材放進 `materials/`，檔名也用日期開頭，並在回饋檔裡寫上檔名。
- 中文、英文或族語都可以；不用在意格式，寫清楚想改什麼、為什麼就好。
- 如果素材是別人的（照片、歌、文字），請註明來源，以及能不能放進遊戲。

## 會怎麼處理
- **小地方會直接改**：服裝、文化細節、族語、食物、小支線點子。改完會整理成摘要，請 Larry 確認；每一筆都記在 `CHANGELOG-from-feedback.md`。
- **大的遊戲改動先等 Larry 同意**：例如主線劇情、玩法規則、地圖、角色設定、大量新內容。會先寫下建議，Larry 同意後才動手。
- 牽涉祭典、禁忌或神聖地點的內容，會盡量請族人或文化顧問確認後才放進遊戲。

# Kristen's feedback folder (English)

This folder is for Kristen (the main repo holder) to drop feedback, notes, references and materials. Development reads it to learn from and to act on.

## How to add something
- **One note per file**, named with the date first: `2026-11-20-outfit-details.md`. Copy `TEMPLATE.md` to start.
- **Photos, scans, recordings, documents** go in `materials/`, also date-prefixed; mention the file name in your note.
- Chinese, English or Tao are all fine. No special format needed: just say what should change and why.
- If a material belongs to someone else (photo, song, text), note the source and whether it may be used in the game.

## What happens next
- **Small items are adapted directly**: outfits, cultural details, language, food, small side-quest ideas. Each change is summarised for Larry to approve and logged in `CHANGELOG-from-feedback.md`.
- **Major game changes wait for Larry's approval**: main story, game rules, the map, character design, or large new content. A proposal is written first; work starts only after Larry agrees.
- Anything about ceremonies, taboos or sacred places is checked with Tao community members or the cultural consultant where possible before it goes into the game.
