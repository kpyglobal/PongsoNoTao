# 蘭嶼食物主權遊戲 企劃雛形 v0.1

> 本文件為初步雛形，內容將由達悟族人確認與修正。
> 標示 **【待確認】** 的項目為設計者不確定、需族人或族語老師確認的內容。
> 標示 **【待族人提供】** 的項目為需由族人補充的資料（例如族語名稱、部落差異）。

---

## 0. 文化聲明（建議放在遊戲開頭）

遊戲中呈現的男女分工、禁忌與飲食規範，以達悟族傳統文化中的一般性做法為設計起點，不代表所有家庭、部落或時代都完全如此。各部落在祭儀時程、禁忌細節與飲食習慣上各有差異，現代家庭的分工也已有許多變化。

遊戲中不模擬祭儀本身，只呈現族人同意公開的飲食與生活面向。

## 1. 遊戲概要

| 項目 | 內容 |
|---|---|
| 暫定名稱 | 【待定】（建議由族人命名，或使用族語詞彙） |
| 類型 | 季節循環 × 生活模擬 × 文化學習 |
| 核心主題 | 食物主權：誰決定吃什麼、怎麼取得、怎麼分享、怎麼保存 |
| 玩家角色 | 族人男青年、族人女青年、男旅人、女旅人 |
| 舞台 | 蘭嶼六大部落 |
| 時間單位 | 達悟三季曆，一個遊戲年為一個完整循環 |

### 1.1 設計目標

1. 讓玩家理解達悟族的食物取得方式依循海洋與季節。
2. 讓玩家理解男女分工是**互補**的：沒有任何一方的工作能單獨讓食物進入家庭。
3. 讓玩家理解禁忌是資源管理、生態保護與社會秩序的一部分。
4. 讓旅人玩家學會「尊重換來關係」，而不只是遵守規則。
5. 讓玩家思考現代生活對傳統食物體系的影響。

## 3. 時間系統：三季曆

| 季節 | 族語 | 大約時間 | 食物重點 |
|---|---|---|---|
| 飛魚季 | Rayon | 約 2–6 月【待確認】 | 捕飛魚、處理與曬飛魚為主 |
| 飛魚結束期 | Teyteyka | 約 7–10 月【待確認】 | 收藏飛魚乾、其他漁撈、陸蟹季 |
| 等待飛魚期 | Amiyan | 約 11–1 月【待確認】 | 農耕、整地、造船、食用存糧 |

### 3.1 部落自主決定飛魚季

1. 每個遊戲年開始，由**紅頭部落**率先舉行招魚祭，宣告飛魚季開始。
2. 其他五個部落在之後各自決定開始時間。
3. 地圖上每個部落顯示自己目前的季節狀態。
4. 旅人跨部落移動時，必須確認**當地**的狀態，不能套用其他部落的規則。

**【待族人提供】**
- 其他部落開始時間的實際決定方式與先後順序
- 各部落飛魚季中的重要時間點（例如收藏、終食）是否也各自決定

### 3.2 季節中的重要飲食時間點

| 時間點 | 遊戲中的效果 | 備註 |
|---|---|---|
| 飛魚季開始 | 解鎖捕飛魚，暫停捕礁岩魚 | 遊戲只呈現「季節開始」，不模擬祭儀 |
| 飛魚收藏 | 曬好的飛魚乾進入糧倉 | 【待確認名稱與時間】 |
| 飛魚終食 | 此後剩餘飛魚乾不可再食用 | 【待確認名稱、時間、剩餘飛魚乾的處理方式】 |

## 6. 食物主權核心機制

### 6.1 四個數值

| 數值 | 意義 | 影響 |
|---|---|---|
| 糧倉值 | 家庭存糧（主食、飛魚乾、其他魚乾） | 不足時家人挨餓，無法度過等待飛魚期 |
| 生態值 | 海洋與陸地資源健康度 | 過度採集會讓下一季資源減少 |
| 部落關係值 | 與船組、親族、鄰居的關係 | 影響合作任務、分享回饋 |
| 文化尊重值（旅人專屬） | 旅人對當地文化的尊重程度 | 解鎖更深入的飲食體驗 |

### 6.2 魚類分類與分配

1. 男青年捕魚回來後，必須正確分辨女人魚、男人魚、老人魚。
2. 女青年依分類處理與烹煮。【待確認：不同類別的魚是否使用不同鍋具、餐具、處理位置】
3. 分錯時，系統讓族人長輩出面說明，玩家重新分配。
4. 目的：讓玩家理解「辨認食物的知識」是食物主權的基礎。

### 6.3 漁獲分享

- 同一艘船的漁獲須分給船組成員。
- 大船漁獲依船組規矩分配給各家庭。【待確認分配方式】
- 私藏漁獲會降低部落關係值。
- 對比：旅人用「購買」取得食物，族人用「分享」取得食物。

### 6.4 飛魚季的捕撈規範

- 飛魚季期間，男性專注捕飛魚，不捕礁岩魚，讓礁岩生態休養。
- 飛魚的處理、烹煮、食用有特定規矩。【待確認具體規矩，例如是否可與其他魚混煮、是否可用特定方式烹調】
- 違反時生態值或部落關係值下降。

### 6.5 糧倉與「剛好」原則

- 曬好的飛魚乾是一整年的重要蛋白質來源。
- 飛魚終食之後，剩餘飛魚乾不可食用。
- 存太少：挨餓。存太多：浪費。玩家要學會「剛好」。

### 6.6 陸蟹與潮間帶的永續採集

- 陸蟹：避開抱卵母蟹，否則生態值大幅下降。
- 潮間帶：只取需要的量，太小的不採。【待確認族人的採集規矩】
- 採集只能在退潮時進行（遊戲內有潮汐時鐘）。

## 8. 任務設計

### 8.1 主線：一條飛魚的旅程（飛魚季）

| 步驟 | 角色 | 內容 |
|---|---|---|
| 1 | 男青年 | 準備拼板舟與漁具 |
| 2 | 男青年 | 部落宣告飛魚季開始後出海捕飛魚 |
| 3 | 男青年 | 回到灘頭，依規矩處理與分配漁獲 |
| 4 | 女青年 | 接手處理飛魚，依種類分類 |
| 5 | 女青年 | 曬魚，飛魚乾進入糧倉 |
| 6 | 女青年 | 烹煮家庭餐點 |
| 7 | 旅人（同時期） | 在部落外圍活動，透過族人朋友了解今天發生的事，不進入灘頭 |

### 8.2 支線：水芋田的一年

| 步驟 | 季節 | 角色 | 內容 |
|---|---|---|---|
| 1 | 等待飛魚期 | 男青年 | 開墾、整地、引水 |
| 2 | 【待確認】 | 女青年 | 種植水芋 |
| 3 | 全年 | 女青年 | 除草、照顧田地 |
| 4 | 【待確認】 | 女青年 | 採收 |
| 5 | 非祭典時期 | 旅人 | 在女青年帶領下協助採收、學習料理 |

### 8.3 支線：潮間帶的早晨

- 角色：女青年（可帶女旅人或男旅人）
- 條件：退潮時段
- 內容：辨認可採集的貝類、海藻，只取需要的量
- 學習卡：潮間帶是女性的重要食物來源【待確認族人對此的說法】

### 8.4 支線：夜晚的陸蟹

- 角色：女青年（可帶旅人）
- 條件：特定季節夜間
- 內容：抓陸蟹，避開抱卵母蟹
- 現代事件：路上車輛造成陸蟹路殺，玩家可選擇協助護送陸蟹過馬路

### 8.5 支線：新船下水的芋頭（選用）

- 族人造新船落成時，會用大量芋頭與食物分享。【待確認具體做法與是否適合呈現】
- 男青年：造船、準備牲畜
- 女青年：大量種植、採收芋頭
- 旅人：是否可觀看，依主人家庭邀請決定【待確認】

### 8.6 旅人專屬任務：學會被邀請吃飯

- 文化尊重值達到一定程度後，族人邀請旅人到家中用餐。
- 旅人學習用餐禮儀、認識哪些食物給誰吃。
- 完成後解鎖「達悟餐桌」圖鑑頁。

## 9. 旅人文化尊重系統

### 9.1 情境與回應

| 情境 | 系統回應 | 尊重值 |
|---|---|---|
| 飛魚季想進入灘頭 | 族人出面說明灘頭在此時的意義，請旅人離開 | 堅持進入：下降 |
| 飛魚季想觸碰拼板舟 | 說明禁忌，邀請「季節結束後再來」 | 遵守：上升 |
| 想靠近祭典或拍照 | 婉拒，提供「在遠處安靜離開」選項 | 安靜離開：上升 |
| 觸碰曬魚架上的魚 | 女青年說明這是家庭一整年的糧食 | 下降 |
| 未經同意拍攝族人或家屋 | 解鎖「請先詢問」學習卡 | 下降 |
| 主動詢問能不能幫忙 | 族人帶旅人參與適合的工作 | 上升 |
| 想購買飛魚當伴手禮 | 族人說明相關規矩【待確認】 | 依選擇變化 |
| 在潮間帶過度採集 | 女青年提醒只取需要的量 | 下降，生態值下降 |

### 9.2 尊重值解鎖內容

| 尊重值等級 | 解鎖 |
|---|---|
| 初訪 | 基本導覽、品嘗部落餐點 |
| 學習中 | 跟族人體驗潮間帶、水芋田 |
| 受信任 | 非飛魚季拼板舟體驗、聽長輩講食物故事 |
| 朋友 | 被邀請到家中用餐 |

## 10. 現代挑戰事件（選用）

讓玩家在傳統與現代之間做選擇，理解食物主權面臨的壓力。

| 事件 | 內容 | 玩家選擇 |
